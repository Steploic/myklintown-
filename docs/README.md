# Documents MyKlinTown

Ce dossier est **privé par défaut**. Le dépôt est public, donc `.gitignore` exclut tout `docs/`, sauf ce fichier et `CHARTE.md`. N'ajoutez une exception que pour un document destiné à être publié. Un fichier commité reste lisible dans l'historique même après sa suppression.

| Dossier | Contenu |
|---|---|
| `entreprise/` | Vie de la société : pacte d'associés, organisation de l'équipe, statuts, démarches CFCE, retours internes. |
| `juridique/` | Textes opposables. Aujourd'hui : convention de collaboration et charte des précollecteurs. À venir : CGU, contrat et charte des abonnés. |
| `reunions/` | Comptes rendus de réunion et documents de décision (dont les corrections et propositions de l'équipe). |
| `tests-terrain/` | Rapports des tests de la plateforme menés par l'équipe. |
| `produit/` | Spécifications fonctionnelles : fonctionnalités, formulaires de demande de devis. |
| `communication/` | Plan de communication, sondage, supports marketing. |
| `identite-visuelle/` | Logos sources : `logos-2026-10/` (et l'archive Drive d'origine dans `source/`), anciennes versions dans `ancien/`. La charte appliquée au site est décrite dans `CHARTE.md`. |
| `livrables/` | Livrables du pilote Technipole (planification). |
| `securite/` | Audits et notes de sécurité. |

Nommage : `Sujet_AAAA-MM-JJ.ext` pour un document daté.
